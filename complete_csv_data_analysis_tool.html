Correction tools

All automatic actions are previewed before they are applied.

Trim leading and trailing whitespace

Removes extra spaces at the beginning or end of non-empty cells. It does not change the meaning of the text.

Remove exact duplicate rows

Keeps the first copy of each fully identical row and removes later exact copies from the working dataset only.

Missing values, invalid values and repeated IDs require judgement. Do not replace or delete them without checking the source or recording a reason.

Manual cell editing

Use the Edit button in the records table to change one cell. Each edit is added to the change log.

After an edit, the data-quality checks and statistical results recalculate from the updated working copy.

Descriptive statistics

Statistics are calculated from non-empty, valid numeric values in the selected column.

Population standard deviation uses N in the denominator. Count includes valid numeric observations only; missing and invalid values are excluded from these calculations.
